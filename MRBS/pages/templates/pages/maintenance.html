Обслуживание сервиса
При опросе сервера Waviot по приборам учета, может возникнуть ситуация, когда опрос по приборам учетам не останавливается. На практике такое не было получено ни разу, но теоретически это может произойти. Например, один из вариантов - выключение сервера, так как состояние опроса и полученные данные хранятся в специальных временных таблицах и меняются во время опроса, то как раз и может возникнуть ситуация зависания. Для ее исправления и создана эта страница.
Состояние опроса по ПУ {{ parse_temp_state }}
Количество записей опроса ПУ во временной таблице {{ parse_temp_count }}
Когда опрос НЕ запущен, то Состояние опроса по ПУ будет равно False, а Количество записей... будет равно 0.
Когда опрос запущен, то Состояние опроса по ПУ будет равно True, а Количество записей... будет НЕ равно 0 и будет увеличиваться. Естественно, больше чем количество ПУ, добавленных в сервисе, оно быть не может. При этом когда фактически опрос сервера Waviot оканчивается, то Количество записей... перестает увеличиваться. Так как существуют еще мероприятия по организации данных, то нормально, когда это число остается неизменным в течение 2-3 минут. После чего при штатной работе, Количество записей... станет равно 0, а Состояние опроса по ПУ станет равно False. Если же этого не происходит в течение 20-30 минут и дольше, то опрос можно считать зависшим.
Для надежной остановки всех внутренних процессов, необходимо перезапустить сервис кнопкой ПЕРЕЗАПУСК. А затем исправить состояние временных таблиц - кнопкой Исправить состояние.
Кнопкой ПЕРЕЗАПУСК также можно пользоваться для профилактических перезапусков сервиса.
